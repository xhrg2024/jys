# 辑佚史智能体 — 人工评估指标体系

## 总览

```
                    ┌─────────────────┐
                    │   检索过程       │
                    │   C: 检索有效性  │
                    └────────┬────────┘
                             │ 产出检索结果
                             ▼
                    ┌─────────────────┐
                    │   推理过程       │
                    │   D: 论证质量    │
                    └────────┬────────┘
                             │ 产出回答
                             ▼
          ┌──────────┴──────────┐
          │                     │
    ┌─────┴─────┐       ┌──────┴──────┐
    │ A: 正确性  │       │ B: 完整性    │
    │  答对了没   │       │  答全了没    │
    └───────────┘       └─────────────┘
```

C 管"拿了什么"，D 管"怎么想的"，A 管"对不对"，B 管"全不全"。四个维度互不交叉。

---

## 评估流程

每题约 20 秒，按 C → D → A → B 顺序，对照日志文件逐项打分。

1. 看日志中的 `[工具调用]` 和工具返回 → 打 **C**
2. 读答案，看推理链是否清晰、逻辑是否自洽 → 打 **D**
3. 逐条对照答案与日志中的检索结果 → 打 **A**
4. 检查检索结果中的关键信息是否在答案中出现 → 打 **B**

---

## 指标 C：检索有效性（1-3 分）

**看日志中的检索全链路是否有效。**

| 分 | 规则 |
|----|------|
| **3** | 三类检索（图谱 + SQL + 向量）全部命中有效结果；tool-calling 正常执行未降级；工具选择覆盖了问题的关键信息需求，既无明显遗漏也无明显冗余 |
| **2** | 存在一项瑕疵：某类检索返回空/低质噪音、tool-calling 选择了冗余工具（如同时调了 kg_explore_relation 又单独调 kg_find_entities 查同一实体）、遗漏了明显应调的工具、或选择了不合适的参数 |
| **1** | 存在严重问题：tool-calling 降级为 fallback、关键工具未被调用、检索结果大面积为空、或工具组合明显不合理（如问关系却未调任何关系类工具） |

> 判定依据：日志中 `[工具调用] 图查询: X条 | SQL查询: X条 | 向量检索: X条` 以及各工具返回内容。工具选择列表见日志中 `来源: LLM Tool Calling (X tools: ...)`。

---

## 指标 D：论证质量（1-3 分）

**看答案是否基于检索结果做了有效推理。不看事实对错（那是 A），不看覆盖多少（那是 B）。**

| 分 | 规则 |
|----|------|
| **3** | 推理链清晰：结论 ← 论据 ← 证据，环环相扣；正确区分了直接证据与间接推论（如用"据 XX 记载"引出直接证据，用"推测""很可能"引出间接推论）；未过度解读或放大检索结果的含义 |
| **2** | 推理基本合理但存在瑕疵：结论与证据之间存在跳跃（如仅凭"A 参与辑佚"就直接推出"A 是清代最重要的辑佚家"而检索中无此比较信息）；主要依赖单一检索源，未综合多源交叉印证；或完整复述了检索内容但缺乏组织 |
| **1** | 推理存在明显缺陷：答非所问、逻辑自相矛盾、因果关系颠倒、或完全不依赖检索结果纯凭模型自身知识回答（回答与日志中检索结果无关联） |

---

## 指标 A：事实正确性（1-3 分）

**只看答案中的事实陈述是否与检索结果一致。不关心数量，只关心对错。**

| 分 | 规则 |
|----|------|
| **3** | 所有可验证的事实均正确。实体名（人名、书名、方法名）逐字一致，数字精确，关系描述准确，年代朝代无出入 |
| **2** | 存在轻微不精确但无完全编造。如：笼统说"清代"但检索显示"乾嘉时期"；说"六百余种"但检索显示"623 种"；说"重要贡献"但检索中无此定性表述 |
| **1** | 存在完全编造的内容——人名错别字（如"马国瀚"应为"马国翰"）、数字严重偏差（如 623 种说成 800 种）、关系颠倒（如 A 继承 B 说成 B 继承 A）、引用了检索结果中完全不存在的文献或来源 |

---

## 指标 B：信息完整性（1-3 分）

**检索结果中已有的关键信息，答案是否充分覆盖。不关心对错（那是 A），只关心够不够。**

| 分 | 规则 |
|----|------|
| **3** | 覆盖日志中检索结果的全部关键信息点，图谱、SQL、向量三类检索产出的相关结果均有体现，无明显遗漏 |
| **2** | 覆盖了主要信息点，但遗漏了检索结果中 1-2 个明显与问题相关的要点。如：关系类问题只说了直接关系路径但没提关联著作；事实类问题只答了人物属性但没提关系网络 |
| **1** | 回答过于简略，检索结果中的大量相关信息未被纳入，导致回答实质内容远少于检索结果所能支撑的范围 |

```
| # | 问题 | C检索 | D论证 | A正确 | B完整 | 备注 |
|---|------|-------|-------|-------|-------|------|
| 1 | ...  | 3     | 2     | 3     | 2     | 推理有跳跃 |
| 2 | ...  | 1     | 1     | 1     | 2     | fallback，答案编造 |
```

## 常见判定示例

| 场景 | C | D | A | B | 说明 |
|------|---|---|---|---|------|
| 检索充分，推理严密，完全正确，信息全覆盖 | 3 | 3 | 3 | 3 | 最佳表现 |
| 检索充分，但结论跳跃（"最重要的"无依据） | 3 | 1 | 2 | 3 | D 扣在过度推断 |
| 检索遗漏 SQL，但图谱+向量撑起了回答 | 2 | 2 | 3 | 2 | C 扣在缺一类，B 扣在少了 SQL 能提供的内容 |
| tool-calling 降级，答案纯靠模型知识编造 | 1 | 1 | 1 | 1 | 全链路失败 |
| 检索结果丰富，但答案只用了图谱部分，忽略 SQL | 2 | 2 | 3 | 1 | B 严重扣分 |
| 人名写错一个字，其他都好 | 3 | 3 | 1 | 3 | A 单点问题，其他不受影响 |

## FACTUAL（2 题）

### 1. 《永乐大典》有哪些编纂者？各自担任什么角色？

- **预期检索源**: DB authors 表 + document_author_links
- **应包含**: 解縉（总纂）、姚廣孝（主编）、王景（编修）、胡廣（编修）、金幼孜（编修）
- **验证点**: 人数准确、角色名称正确、无编造人名

### 2. 《初學記》和《藝文類聚》分别是什么朝代、什么体例的类书？

- **预期检索源**: DB documents 表元数据
- **应包含**: 初學記=唐/事文一体/开元十五年(727)；藝文類聚=唐/事文一体/武德七年(624)
- **验证点**: 朝代正确、体例正确、编纂时间精确

## RELATION（2 题）

### 3. 惠栋和马国翰在辑佚学上有什么关联？

- **预期检索源**: KG — 惠栋（度数 15）→ RELATES → 辑佚 → RELATES → 马国翰（度数 14）
- **应包含**: 两人通过"辑佚"方法相连；惠栋为吴派/惠派创始人，马国翰受其影响；各自代表著作（易汉学 vs 玉函山房辑佚书）
- **验证点**: 多层路径被检索到、双方著作被提及、关系描述准确

### 4. 《永乐大典》对清代辑佚学产生了什么影响？

- **预期检索源**: KG — 永乐大典（度数 17）关联全祖望、朱筠、戴震、邵晋涵、周永年等
- **应包含**: 朱筠奏请从《永乐大典》辑佚；四库全书馆的设立；全祖望/戴震/邵晋涵等人参与辑录
- **验证点**: 多位学者被提及、辑佚机制被说清

---

## CHAIN（2 题）

### 5. 唐宋明三代类书的编纂体例有什么演变？

- **预期检索源**: DB documents 表 — 唐（初學記/藝文類聚：事文一体）、宋（太平御覽：类事、冊府元龜：类事）、明（永樂大典：事文一体、三才圖會：类事）
- **应包含**: 各代代表类书、体例特点（事文一体→类事→混合）、规模变化
- **验证点**: 三代均有覆盖、体例描述正确、演变逻辑清晰

### 6. 清代辑佚学从清初到清末大致经历了怎样的发展脉络？

- **预期检索源**: KG — Time 实体（清初/乾嘉时期/清末民初） + 各时期 Scholar
- **应包含**: 清初零星辑佚→乾嘉大规模辑佚（惠栋/戴震/马国翰/严可均/黄奭等）→清末补续（王仁俊等）
- **验证点**: 分阶段叙述、各阶段代表人物正确、逻辑连贯

## METHOD（2 题）

### 7. 什么是"二重证据法"？谁提出的？在辑佚中如何应用？

- **预期检索源**: KG — 二重证据法 → RELATES → 王国维
- **应包含**: 王国维提出；利用地下新材料（甲骨文/金文）补正纸上文献记载
- **验证点**: 方法定义准确、提出者正确、应用场景合理

### 8. 戴派辑佚法的核心特点是什么？与惠派辑佚法有何不同？

- **预期检索源**: KG — 戴派辑佚法→戴震 + 惠派辑佚法→惠栋
- **应包含**: 戴派"以古征实、辑佚与考证结合"；惠派"凡古必真、凡汉必好、辑佚视野局限于经部"
- **验证点**: 双方特点均有描述、差异对比清晰
